Circuitoon's simulator runs ngspice 45.2 (engine build 45.2-1), compiled to WebAssembly as
a separate, replaceable file (ngspice.wasm).

ngspice is distributed under the modified BSD licence (BSD-3-Clause), except for these components,
which keep their own licences:

- src/frontend/numparam: GNU Lesser General Public License, version 2 or later (LGPLv2+).
- src/maths/sparse: the Sparse 1.3 licence (permissive, MIT-style).
- src/frontend (parse-bison.c, parse-bison.h) and src/spicelib/parser (inpptree-parser.c,
  inpptree-parser.h): parsers generated by GNU Bison. The Bison skeleton is GPLv3+ with the Bison
  special exception, which lets its output be distributed under any terms; the parsers themselves
  are ngspice's (BSD-3-Clause).

The KLU solver (SuiteSparse) is not compiled into this build (--disable-klu).

ngspice.wasm also contains the Emscripten runtime: Emscripten's own libc and runtime code (MIT or
University of Illinois/NCSA), musl libc (MIT) and LLVM compiler-rt (Apache-2.0 with LLVM exceptions).

The licence texts are in these files beside this one:

- LICENSE-ngspice.txt: ngspice's COPYING (the BSD-3-Clause text and copyright, the XSPICE
  public-domain notice, and the GNU LGPL 2.1 text).
- LICENSE-LGPL-2.txt: the GNU Library General Public License, version 2 (numparam is LGPLv2 or later).
- LICENSE-emscripten.txt: the Emscripten, musl and compiler-rt licences.

Directories compiled into this build that mention another licence (from the build's scan):
frontend: parse-bison.c parse-bison.h
frontend/numparam: mystring.c spicenum.c xpressn.c
spicelib/parser: inpptree-parser.c inpptree-parser.h

The exact ngspice source tarball, our patches, the build script, the emsdk version and relinking
instructions are published with this engine build at:
https://github.com/MBarc/circuitoon/releases/tag/engine-ngspice-45.2-1

You may replace ngspice.wasm with your own build of the same source (see RELINK.md in that
release); Circuitoon loads it by file name.
